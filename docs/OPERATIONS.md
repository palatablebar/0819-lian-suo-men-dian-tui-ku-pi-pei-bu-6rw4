# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

## 月底退库按时交

1. 在“来源截止日”填入本次要覆盖的最后一天；留空则取来源中最大的业务日。
2. 点“预览匹配簿”。先看提示行：输入、采信、隔离与匹配行逐项对平时显示已对平，否则列出待处理记录键。
3. 截止日之后的退库显示为“截止后延后”，不会占用任何入库；补录仓单只在入库日当天及之后可用。
4. 若提示可签发，填写 3 至 200 字签发说明并点“签发新版本”。同一来源同一截止日重复提交只会回读原签版。
5. 迟到的入库记录到齐后，把截止日推后并再次签发；新签版会列出相对上一版的匹配变化。
6. 在“签版历史”点任一旧签版可回读当时冻结的匹配簿与依据，并下载该签版证据。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次与签版。恢复时使用原 Docker Compose 数据卷。
